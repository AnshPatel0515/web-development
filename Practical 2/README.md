# StudentHub - Practical 2

Practical 2 focuses on clean semantic HTML structure and accessible navigation.
A beginner-friendly set of semantic HTML5 pages for the Web Development Frameworks practical.

## Pages included

Home, About, Register, Login, Dashboard, Events, Profile, Contact, Admin, FAQ, and Feedback.

## How to open

1. Open this folder in Visual Studio Code.
2. Open `index.html` in a web browser (or use the VS Code Live Server extension if available).
3. Use the navigation menu to visit the other pages.

## What the practical demonstrates

- Semantic HTML elements: `header`, `nav`, `main`, `section`, `article`, `aside`, and `footer`.
- A consistent navigation menu linking all pages.
- Accessible form labels, heading structure, keyboard focus, and a skip-to-content link.
- A small shared `style.css` file for readable presentation.

The forms are static examples and do not save data. See `ACCESSIBILITY_CHECKLIST.md` for the review checklist.
