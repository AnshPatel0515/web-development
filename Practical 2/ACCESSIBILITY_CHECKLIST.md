# StudentHub Practical 2 - Accessibility Checklist

Use this checklist when you review the pages:

- [x] Each page declares English with `lang="en"` and includes a mobile viewport setting.
- [x] Each page has a descriptive browser title and one main page heading.
- [x] The shared page layout uses `header`, `nav`, `main`, and `footer` landmarks.
- [x] Navigation links have clear names and the current page is marked with `aria-current`.
- [x] The skip link lets keyboard users jump to the main content.
- [x] Each form input has a matching visible `label` and a unique `id`.
- [x] Required form fields use the HTML `required` attribute.
- [x] Links and form controls can be reached using the keyboard; focus has a visible outline.
- [x] Content is grouped with meaningful headings, sections, and articles.
- [ ] If you add an image, write useful alternative text with the `alt` attribute.
- [ ] Before submission, open each page in a browser and check every navigation link.

Note: the forms are static HTML examples. They do not save or send information.
