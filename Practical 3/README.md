# StudentHub - Practical 3

Practical 3 focuses on responsive layouts, Flexbox navigation, and CSS Grid cards.
This folder contains the same beginner-friendly StudentHub pages, now styled to fit phones, tablets, and desktop screens.

## Open the project

1. Open this folder in Visual Studio Code.
2. Open `index.html` in a browser. You can also use the VS Code Live Server extension.
3. Select pages from the navigation menu.
4. Make the browser window narrower and wider to see the layout change.

## What is added in Practical 3?

- **Mobile-first CSS:** pages start with a one-column layout that works on a phone.
- **Flexbox:** the navigation links wrap neatly when the screen is narrow.
- **CSS Grid:** the Events page changes from one column to two columns and then three; the Dashboard places its notice beside the main content on wider screens.
- **Media queries:** the layout changes at 700px and 1000px screen widths.
- **Consistent styling:** shared colours, spacing, form controls, and visible keyboard focus.

The HTML forms are examples only. They do not save or send information. See `RESPONSIVE_CHECKLIST.md` for a practical review list.
