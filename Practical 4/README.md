# StudentHub - Practical 4

Practical 4 focuses on JavaScript interactions, a remembered theme, a slider, and a modal.
Practical 4 adds simple JavaScript interactions to the StudentHub pages.

## Run it
Open `index.html` in a browser. No server is needed for these local interactions.

## Included interactions
- Expand/collapse navigation menu on smaller screens.
- Light/dark theme switch saved in `localStorage`.
- Dismissible welcome notice.
- Previous/next highlight slider.
- Accessible browser dialog (modal) with open and close buttons.
- FAQ answers that expand using HTML `details` and `summary`.

The JavaScript is in `app.js`. Read it from top to bottom; each part checks that its buttons exist before attaching events, so the shared file works on all pages.
